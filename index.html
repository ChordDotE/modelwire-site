Put an end-of-life badge in your README

Every tracked model has a badge on this site — 570 of them. It is a plain SVG file. No script, no account, nothing to install. You paste one line, and the image changes on its own when the provider announces an end of life for that model.

1. Build the URL

Take the model id, lowercase it, and replace every character outside a-z 0-9 . _ - with a hyphen — including the slash between provider and model. That is the slug.

For openai/gpt-4o:

openai/gpt-4o  →  openai-gpt-4o
https://chorddote.github.io/modelwire-site/badge/openai-gpt-4o.svg

2. Paste it

[![end of life](https://chorddote.github.io/modelwire-site/badge/openai-gpt-4o.svg)](https://chorddote.github.io/modelwire-site/models/openai-gpt-4o.html)

Linking the badge to the model page is optional, but it gives the reader somewhere to go when the colour changes.

Not sure of the slug? Every badge, with its exact slug and current state, is listed in badge/index.json.

3. What the badge is saying

  • none announced (green) — we have not found an end-of-life announcement for this model. That is all it says. It is not a promise from the provider, and it is not a statement that the model will keep running. Providers can announce a shutdown at any time, and open-weight models are never given an end-of-life date at all.
  • 1234 days left (2029-01-01) — the provider published this date and did not qualify it. Yellow, then orange under 90 days, then red under 30.
  • not sooner than 2027-01-01 — the provider's own qualifier, kept verbatim. The provider has not committed to this date. We do not turn it into a firm one.
  • announced, date not confirmed (grey) — an end of life is announced, but what the provider put in the date column is not a calendar date.
  • retired 2024-01-04 (red) — the date has passed.
  • removed from catalog (grey) — the model is no longer listed by the source catalog, with no end-of-life announcement to go with it.

Green is not a safety rating. It means "nothing announced as of the last observation" — nothing more. A model can go from green to a 30-day countdown in a single announcement, and that is exactly what the badge is for: it changes without you having to check.

End-of-life announcements are collected from the official deprecation pages of openai, anthropic, x-ai and cohere. A model from any other provider will show none announced because there is no deprecation page to read, not because it has been cleared.

Why this exists

Every LLM provider publishes its current prices and model list. None of them keep a public change history.

So if you run LLMs in production, you cannot answer these:

  • When did our API cost go up?
  • When was this model's deprecation announced?
  • What price did we quote against last quarter?
  • When did the context window shrink?

ModelWire reads the public catalogs twice a day and records only the moments something changed. Once written, a row is never rewritten.
