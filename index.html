Why this exists

Every LLM provider publishes its current prices and model list. None of them keep a public change history.

So if you run LLMs in production, you cannot answer these:

  • When did our API cost go up?
  • When was this model's deprecation announced?
  • What price did we quote against last quarter?
  • When did the context window shrink?

ModelWire reads the public catalogs twice a day and records only the moments something changed. Once written, a row is never rewritten.

Historical Dataset — $1

⚠️ Coverage starts 2026-08-09. This dataset contains no data from before that date. No public historical record of LLM pricing existed before this project began collecting — we will not pretend otherwise. Today it covers 2 days.

What you get:
