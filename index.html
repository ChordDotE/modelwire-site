なぜこれが必要なのか

各LLMプロバイダは価格とモデル一覧を公開していますが、いずれも「現在の値」しか出していません。変更履歴を残していないのです。

そのため、LLMを本番で使っている開発者は次の問いに答えられません。

  • うちのAPIコストは、いつから上がったのか？
  • このモデルのEOLは、いつ告知されたのか？
  • 先月の見積もりの前提価格は、いくらだったのか？
  • context窓が縮小されたのは、いつか？

ModelWire は公開APIを毎日観測し、変化があった時点だけを追記専用の台帳に記録します。一度書いた記録は書き換えません。

完全なデータセットと変更通知

閲覧はすべて無料です。有料になるのは次の2つだけです。

  • 全モデルの完全なデータを一括で持ち帰る（CSV / JSON / Parquet）
  • 指定したモデルが変わったときに通知を受け取る（メール / Slack / Discord / Webhook）

価格と申込は準備中です。RSSフィードを購読しておくと、公開時にお知らせします。

ModelWire は非公式のプロジェクトです。掲載しているLLMプロバイダのいずれとも提携・関連はありません。

掲載しているのは公開APIから取得した事実（数値・日付・識別子）のみです。各値の一次ソースは各ページのリンク先を参照してください。
