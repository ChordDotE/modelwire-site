Privacy

This site is a set of static files. It has no accounts, no login and no comment box, so there is nothing here for you to give us.

What is collected

  • The page you landed on, and the page you came from (the referrer), if your browser sends one.
  • Country, browser and operating system, as coarse categories.
  • Clicks on a small number of named links — the dataset link and the feed links — counted as totals, not tied to you.

What is not collected

  • No cookies. Nothing is written to your browser's storage.
  • No cross-site tracking and no advertising. Nothing here is shared with an ad network.
  • No full IP address is stored. It is used in transit to derive a country and is not retained by us.
  • No profile. There is no identifier that follows you between visits or between sites.

Who processes it

Page-view counting is done by Umami. Search-engine operators separately report which queries led people here; that report contains aggregate counts, never individuals. GitHub serves the files and, like any web host, sees the request.

If you buy something

Payment is handled by Polar as Merchant of Record. Your payment details are entered on Polar's own pages and never reach this site. We receive the fact that a sale happened and the email address needed to deliver the file.

Opting out

The counter is a single script file. Any content blocker, or a browser with tracking protection on, stops it; nothing on this site breaks when it is blocked. Everything on this site is readable with JavaScript switched off entirely.

Questions

This is an independent project run by one person, not a company. Corrections and questions can be raised through the primary sources linked on every page.

ModelWire is an unofficial project. It is not affiliated with, or endorsed by, any listed provider.

Only facts obtained from public APIs are stored and redistributed — numbers, dates, identifiers. Each value links to its primary source.
