提供終了バッジを README に貼る

追跡中の全モデルにバッジがあります（545枚）。実体は SVG ファイル1枚です。スクリプトもアカウントも要りません。1行貼っておけば、そのモデルの提供終了が告知された時点で画像のほうが勝手に変わります。

1. URL を組み立てる

モデルIDを小文字にし、a-z 0-9 . _ - 以外の文字をすべてハイフンに置き換えます（提供元とモデル名の間のスラッシュもハイフンになります）。これが slug です。

openai/gpt-4o の場合:

openai/gpt-4o  →  openai-gpt-4o
https://chorddote.github.io/modelwire-site/badge/openai-gpt-4o.svg

2. 貼る

[![end of life](https://chorddote.github.io/modelwire-site/badge/openai-gpt-4o.svg)](https://chorddote.github.io/modelwire-site/ja/models/openai-gpt-4o.html)

モデル別ページへのリンクは任意ですが、色が変わったときに読み手の行き先ができます。

slug が分からない場合は、全バッジの slug と現在の状態をbadge/index.json に載せています。

3. バッジが言っていること

  • none announced（緑）— そのモデルの提供終了の告知が見つかっていない、という意味です。それ以上のことは言っていません。提供元の約束ではありませんし、「終了しない」という意味でもありません。提供元はいつでも終了を告知できますし、オープンウェイトのモデルはそもそも提供終了が告知されません。
  • 1234 days left (2029-01-01) — 提供元がこの日付を公表し、但し書きを付けていないもの。残り90日で橙、30日で赤になります。
  • not sooner than 2027-01-01 — 提供元自身の但し書きを原文のまま残しています。提供元はこの日付を確定させていません。確定日には変換しません。
  • announced, date not confirmed（灰）— 提供終了の告知はあるものの、日付欄の記載が暦日として読めないもの。
  • retired 2024-01-04（赤）— その日付を既に過ぎているもの。
  • removed from catalog（灰）— 提供終了の告知が無いまま、カタログから消えたもの。

緑は「安全」の評価ではありません。「最終観測の時点で告知が見つかっていない」という意味だけです。告知1本で緑から残り30日に変わることがあり、それを自分で見に行かずに知るためのバッジです。

提供終了の告知は openai / anthropic / x-ai / cohere の公式ドキュメントから収集しています。それ以外の提供元のモデルが none announced になるのは、安全だと確認できたからではなく、読むべき提供終了ページが存在しないからです。

なぜこれが必要なのか

各LLMプロバイダは価格とモデル一覧を公開しています。しかし、いずれも変更履歴を残していません。

そのため、LLMを本番で使っていると、次の問いに答えられません。

  • うちのAPIコストは、いつから上がったのか？
  • このモデルの提供終了は、いつ告知されたのか？
  • 先四半期の見積もりの前提価格は、いくらだったのか？
  • context窓が縮小されたのは、いつか？

ModelWire は公開カタログを1日2回読み、値が動いた瞬間だけを記録します。一度書いた行は、二度と書き換えません。
